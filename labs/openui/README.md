# OpenUI codelab

**What to show:** the developer defines a component library, generates instructions for the model, streams OpenUI Lang, and renders each component as it arrives.

**Static:** use a fixed component tree.

**Declarative:** treat a compact component description as data and render through the library.

**Open-ended:** let the model choose a composition of approved library components, then validate props and nesting.

**Mixed:** combine normal assistant text with a live component stream. In production, show the official autofix/validation path for malformed output.
