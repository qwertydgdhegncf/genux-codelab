# Harness / GenUI codelab

**What to show:** a host response can contain normal text plus a fenced UI surface; user actions flow back through the host's event loop.

**Static:** the app's own fixed order card is the control case.

**Declarative:** a fenced payload describes a trusted `Card` and action.

**Open-ended:** the harness chooses from its supported GenUI components; the host remains the security boundary.

**Mixed:** show prose, tool status, UI, and a refresh action together. Compare this with the reference `genui` directory supplied in the assignment.
